  3. 下载三大基础开发软件安装包（先下载好安装包即可，不会装的可以等例会一起装）：

2. 灵魂拷问：Blog 是什么？现在都 2026 年了，Blog 过时了吗？

  • Blog 是什么？ Blog（Web Log，网络日志，简称博客） 就是你在互联网上独立拥有的一个私人网站。你可以在上面发布学习笔记、技术总结、生活随笔、摄影作品甚至个人简历。

  • 已经有朋友圈、小红书、知乎、CSDN 了，为什么还要自己搭 Blog？Blog 过时了吗？ 恰恰相反！在算法推荐和商业平台横行的今天，独立博客反而是程序员圈子里最酷的“赛博自留地”：

对比维度商业内容平台（CSDN / 知乎 / 社交平台）你自己搭建的独立博客（Hexo + GitHub Pages）
页面清爽度满屏弹窗广告、VIP 付费解锁、强制登录才能复制代码0 广告、极速加载，排版每一处细节都由你说了算
自由度与所有权格式受限，文章可能因莫名其妙的敏感词被审核或下架源码 100% 掌握在自己手里，想怎么美化、加什么特效全凭喜好
求职与个人品牌淹没在千篇一律的平台模板里，难以体现技术动手能力简历上印一行 https://你的名字.github.io，面试官点开直接加分
社交属性被算法信息流裹挟的点赞之交通过**友链（友情链接）**与全校乃至全球优秀的开发者互换名片

3. 为什么我们用“搭博客”作为 TIC 零基础入门第一课？在这里能学到什么？

很多同学刚进大学学计算机或参加技术社团时，只在黑框框里写过 Hello World 或者算过鸡兔同笼，总觉得“写代码”离“做出一个真正的产品”很遥远。 带你用 Hexo 搭博客，是因为它“麻雀虽小，五脏俱全”。在这个过程中，你会不知不觉打通现代软件开发的全流程：

  1. 体验真实软件是怎么跑起来的（软件开发生命周期）： 真正的软件开发从来不是在一个软件里单打独斗，而是：配置底层环境（Node.js / Git） ➔ 初始化工程脚手架（Hexo） ➔ 编写源码与内容（VS Code + Markdown） ➔ 本地编译构建与调试（localhost） ➔ 部署发布到远程服务器（GitHub Pages）。今天你走完这一遍，以后学前端、后端、小程序，流程全都一模一样！

  2. 理解“静态网站（Static Website）”是怎么回事： 网站通常分为两类：

    • 动态网站（如淘宝、B站）：需要后台服务器和数据库每时每刻实时计算、推送千人千面的内容，租服务器既贵又复杂。

    • 静态网站（如我们的个人博客）：文章写好后内容是固定的。我们只需要一个“加工厂”，把我们写的笔记提前转换成浏览器能看懂的网页文件（HTML + CSS + JavaScript），然后丢到 GitHub Pages 提供的免费服务器上，全世界就能免费、高速地访问你的网站了！

  3. 为什么选择 Hexo 框架？ Hexo 是目前全球最受欢迎的开源静态博客框架之一（基于 Node.js 开发）。它的核心优势就三个字：快、爽、美——几秒钟就能把上百篇 Markdown 笔记编译成完整网页，支持一条命令一键发布到 GitHub，而且社区里有成百上千套开箱即用的神仙主题（见 Hexo 官方主题列表），零前端基础也能改出大师级视觉效果！

三、第一阶段：前置准备——打通网络、账号与三大开发神器

软件开发的第一步叫“搭环境”。就像做饭前要先买好锅碗瓢盆、接通煤气一样

Step 1：下载安装网络加速神器——Watt Toolkit（原名 Steam++）

因为我们要把博客托管在全球最大的代码托管平台 GitHub 上，而国内直接访问 GitHub 经常会遇到网页打不开或连接超时的问题。我们可以借助开源免费的加速工具 Watt Toolkit 来解决。

  1. 打开浏览器，访问 Watt Toolkit 官方网站（或在微软应用商店）。

  1. 根据你的电脑系统（Windows / macOS）下载安装程序并打开。

  2. 打开软件后，在左侧菜单栏找到 “网络加速”。

  3. 在右侧列表中勾选 “GitHub”，然后点击右下角的 “一键加速” 按钮（如果是第一次使用，软件提示安装证书或 Hosts 权限时，请全部点击“确定/允许”）。

Step 2：注册你的程序员身份证——GitHub 账号

可以参考：注册Github账号详细教程【超详细篇 适合新手入门】_github注册-CSDN博客

加速开启后，我们来注册全球程序员的同性交友代码开源社区——GitHub。

  1. 浏览器访问 GitHub 官网，点击右上角的 Sign up（注册）。

  1. 按照提示依次输入你的常用邮箱（Email）、密码（Password）以及用户名（Username）。

    • 起名特别提醒：你的 GitHub 用户名（比如 zhangsan）将来会直接变成你博客的专属网址：https://zhangsan.github.io！所以强烈建议取一个简短、好记、全英文/数字的名字，并且拿小本本记好你的用户名和注册邮箱，后面配置连接时要用！

  2. 去邮箱查收验证码完成验证，即可成功登录 GitHub。

Step 3：安装三大核心软件（Node.js + Git + VS Code）

接下来我们要安装三个贯穿你整个大学编程生涯的核心工具。别被英文名字吓到，先看看它们各自扮演什么角色：

软件名称官方下载链接它在搭博客里起什么作用？
Node.js点击前往官网下载Hexo 框架是用 JavaScript 写的，Node.js 让它能在你电脑上跑起来；同时自带包管理器 npm（相当于程序员的软件商店）。
Git点击前往官网下载帮你管理代码修改历史，并负责把你在电脑上生成的博客网页“打包快递”上传到 GitHub 服务器上。
VS Code点击前往官网下载微软出品的免费编辑器，我们用它来修改博客配置、编写 Markdown 文章并实时预览排版效果。

🔹 1. 安装 Node.js

  1. 打开 Node.js 官方下载页，选择带有 LTS（Long Term Support，长期支持稳定版） 标识的安装包下载（Windows 选 .msi 安装包，Mac 选 .pkg 安装包）。

  2. 双击运行安装包，无脑一路点击 Next（下一步） 即可！

🔹 2. 安装 Git

  1. 打开 Git 官方安装页（Windows 同学进入 Git for Windows 页面），点击下载安装程序。

  • 零基础科普：什么是 localhost:4000？

  • localhost（本地主机）指的是你自己的这台电脑，:4000 是房间门牌号（端口号）。

  • 现在这个网站只运行在你自己的电脑内存里，只有你自己能看到，方便你在正式发到网上之前随便改、随便试错。

  • 当你想继续在命令行里敲其他命令时，只需要回到命令行窗口，按下键盘上的 Ctrl + C，就能关掉这个本地预览服务器。

5. 本地更新的流程

每次你修改了 _config.yml 配置、或者新建/修改并保存了 .md 文章之后，怎么让本地网站刷新出最新内容呢：

  • 为什么要按这个顺序敲？

    1. hexo clean（清理缓存）：把之前旧的缓存文件（db.json）和旧的网页成品（public 文件夹）彻底打扫干净。很多时候你改了文章或配置却发现网页没变化，就是因为忘了跑 hexo clean

    2. hexo g（重新构建）：把刚才新写的《我的第一篇博客》重新编译进静态网页里。

    3. hexo s（启动预览）：再次打开 http://localhost:4000，刷新一下页面——你的《我的第一篇博客》已经出现在首页第一条啦！看满意后，回到命令行按 Ctrl + C 结束本地预览，准备进入最激动人心的全网上线环节！

七、第五阶段：走向世界！连接 GitHub Pages 部署你的专属 github.io 网站

前面我们在 localhost:4000 看到的网站，只有你自己的电脑能打开。现在，我们要借助 GitHub Pages 提供的免费静态网页托管服务，把你的博客正式发布到公网上，生成一个全世界任何人用手机、电脑都能打开的 https://你的用户名.github.io 网址

Step 1：在 GitHub 上创建一个特殊名字的仓库

(提醒：确保你的 Watt Toolkit 加速依然开着！)

  1. 打开浏览器登录 GitHub 官网。

  2. 点击页面右上角头像旁边的 + 号，在下拉菜单中点击 New repository（新建代码仓库）。

  3. 【生死攸关的一步：填写仓库名称 Repository name】： 在 Repository name 输入框里，你填写的名字必须严格遵守以下格式（一字不差，全小写）：

    你的GitHub用户名.github.io

    • 举个例子：假设你的 GitHub 用户名叫 xiaoming123（可以在输入框左边 Owner 下面看到你自己的名字），那你在右边 Repository name 里就必须填 xiaoming123.github.io！

    • 为什么要这么填？ 这是 GitHub Pages 官方文档 规定的特殊暗号。只有当仓库名严格等于 用户名.github.io 时，GitHub 才会自动把这个仓库识别为你的个人主页网站，并免费送你这个同名网址！
